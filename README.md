# Аналитический контур сети пиццерий — снимок кода

Ночной сбор данных из шести систем в один Postgres и витрина поверх него: тринадцать
загрузчиков в цепочке GitHub Actions, 69 миграций, сверка каждой цифры с корпоративной
системой. Собрано с нуля одним человеком за три месяца, в работе каждый день.

**Это снимок, а не рабочий репозиторий.** История коммитов и часть файлов не входят
сюда намеренно: проект живёт внутри компании, и в истории лежат данные сети. Снимок
сделан одним коммитом, чтобы показать код, не раскрывая цифры.

## Что внутри

| | |
|---|---|
| `get_*.py` | 24 загрузчика: продажи, доставка, производство, стопы, рейтинги, склад, найм, заявки техподдержки |
| `.github/workflows/` | 23 workflow; ночная цепочка собрана в `daily_all.yml` |
| `migrations/` | 69 миграций схемы |
| `token_store.py` | OAuth-токен Dodo IS в базе под `pg_advisory_xact_lock` |
| `sheets_retry.py` | повторы к Google Sheets: 5xx и 429 повторяем, 401/403/404 пробрасываем сразу |
| `docs/` | методики расчётов и разбор сверки с эталоном |

## Три вещи, ради которых стоит смотреть

**`daily_all.yml` — один оркестратор вместо тринадцати расписаний.** Когда у каждого
загрузчика было своё расписание, GitHub при нехватке раннеров задерживал запуск и
выпускал накопившееся пачкой; на concurrency-группу остаётся ровно один ожидающий
прогон, и каждый следующий вытеснял предыдущий как `cancelled` — 74 отмены за два
месяца, без единой ошибки в логах. Теперь одно расписание и цепочка `needs`.
Неочевидная ловушка описана комментарием прямо в файле: вызванному workflow нельзя
оставлять общую concurrency-группу, иначе он ждёт группу, которую держит вызывающий.

**`token_store.py` — одноразовый refresh-токен и двое писателей.** Dodo IS
проворачивает refresh-токен при каждом обновлении. Пока пара жила в секретах GitHub,
любой параллельный рефреш (соседняя джоба или локальный запуск) оставлял в секрете
уже сожжённый токен. Лечится не ретраями, а единственным местом хранения: строка в
базе, блокировка берётся до чтения, обновление за 15 минут до истечения.

**`docs/stops-lost-revenue-reconciliation.md` — как сходится цифра.** Разбор сверки
упущенной выручки с корпоративной системой: от расхождения в 3,6 раза до 100,8% по
пиццериям и 99,9% по секторам. Абсолютные суммы заменены на `×××`, проценты
сходимости оставлены — история именно в них.

## Чего здесь нет и почему

- **Истории коммитов** — в ней данные сети.
- **Загрузчиков и схем управленческой отчётности** — раскрывают структуру статей.
- **Плана выручки** и справочника точек — коммерческая информация и внутренние
  идентификаторы. Вместо справочника — `yakutsk_units.example.json` той же формы.
- **Абсолютных сумм в документах** — заменены на `×××`; проценты и методики на месте.
- **`.env`** — ключи никогда не коммитились, нужные переменные перечислены в
  `.env.example`.

Как есть код не запустится: нет доступов и справочника точек. Он здесь, чтобы его
читали, а не запускали.
